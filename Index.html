✅ Seedha Phone Pe Install Karo (No IDE!)

🍎 iPhone pe kaise install karein

  1. Safari mein downloaded index.html kholo
  2. Neeche Share button (□↑) dabao
  3. "Add to Home Screen" select karo
  4. Done! App home screen pe aa jayegi

🤖 Android pe kaise install karein

  1. Chrome mein downloaded index.html kholo
  2. Top-right ⋮ menu → "Add to Home screen"
  3. Ya address bar mein install icon aayega
  4. Done! App install ho jayegi
